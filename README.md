🌱 Kerala GreenCycle

Smart Organic Waste Management System for Kerala

Kerala GreenCycle is a software platform designed to help manage biodegradable waste generated by restaurants and hotels.

The system connects restaurants, waste collectors, processing centres, government authorities, and gardens.

♻️ Main Workflow

Restaurant
↓
🥬 Biodegradable Waste
↓
🚛 Waste Collection
↓
🏭 Central Processing Centre
↓
🌱 Compost / Organic Manure
↓
🏞️ Government Gardens / Private Buyers

🚀 Features

- 🏨 Restaurant registration
- 🥬 Organic waste submission
- 🚛 Waste collection management
- 💰 Restaurant reward calculation
- 🌱 Compost production tracking
- 🏛️ Government dashboard
- 📊 Waste-management statistics

🛠️ Technologies

- Python
- Streamlit
- PostgreSQL
- Pandas
- Data Science / Machine Learning

▶️ Run Locally

Install the required packages:

pip install -r requirements.txt

Run the application:

streamlit run app.py

🌍 Deployment

The application can be deployed using Streamlit Community Cloud with the GitHub repository.

For production deployment, PostgreSQL should be used as the persistent database instead of local SQLite storage.

🌱 Project Goal

The goal of Kerala GreenCycle is to reduce biodegradable waste from restaurants, improve municipal waste management, create useful compost, support government gardens, and provide an incentive for restaurants to properly separate organic waste.

«Waste is not the end — it is a resource for a greener Kerala. 🌱»
